The front-end mobile application for ShefAmma, available on the Google Play Store, providing an intuitive and user-friendly interface for customers.

**Features**

User Interface: Designed with React Native, optimized for performance and usability.
Real-Time Location Tracking: Displays live order tracking using Google Maps API.
Order Placement and History: Allows users to browse, select, and reorder from past orders.
Secure Payments: Integrated with leading payment gateways for seamless transactions.
Push Notifications: Real-time updates on order status and promotions.

**Technologies Used**

Frontend Framework: React Native
APIs: Google Maps API, REST APIs from ShefAmma Backend
Build Tools: npm, Expo
